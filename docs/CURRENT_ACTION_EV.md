# 当前行动 EV 有限模型 v1

快速分析在完整逐步记录、轮到自己行动且只剩一名对手时，自动展示候选动作表。范围权益来自当前快速分析（有行动修正结果时优先使用），不额外发起蒙特卡洛任务。新状态未完成计算时不沿用旧状态数值。

## 收益定义

收益为从当前决策起的净筹码，不计此前投入，不计抽水或 ICM。

- 弃牌为 0；不需要跟注时只提供过牌，不列免费弃牌。
- 当前跟注成本为 C，底池为 P；直接摊牌时 EV = e(P+C) − C。
- 主动下注／加注追加 H，对手匹配追加 V。对手弃牌时赢得 P（自己的未跟注下注退回）；对手再加注时固定弃牌，损失 H；对手跟注时 EV = e(P+H+V) − H。
- 因而主动动作的 EV = fP − rH + (1−f−r) × 跟注分支 EV。全下后 r=0，其概率质量归入跟注分支。

允许后续下注且尚未到河牌时，在匹配投入后再展开一次对手试探下注：B = min(向上取整的半底池, 双方剩余筹码)。自己按模型收益在跟注和弃牌间选择；其余动作直接摊牌。此后分支价值为 (1−p)eP + p max(0,e(P+2B)−B)。当前投入成本在外层扣除。

候选加注包括当前最高额加上跟注后底池的半池、一池、两池，以及双方可匹配筹码上限。遵守最小加注和重新开放加注权；重复金额合并。对手可匹配上限低于最小合法加注时，只有自己合法的短筹码全下才列入。候选集不代表所有合法金额。

## 假设和边界

基准弃牌、再加注、后续试探下注概率默认分别为 25%、8%、35%，可在界面调整；未从玩家数据校准。所有尺度使用同一响应概率。各响应事件与手牌和牌面独立，各分支复用同一摊牌权益；没有计算条件跟注范围。过牌后当前街的主动下注不单独展开。不能把候选最高值当作完整策略最优值。

有利／不利情景将当前权益上下移动至少 8 个百分点（或更大的 1.96 倍抽样标准误差），同时变动弃牌、再加注和试探概率。这是输入压力测试，不是重新推断范围。每个候选传播权益误差，按保守容差保留接近的候选；三情景共同候选不表示范围稳定性已得到验证。

多名在局对手、边池或未匹配的投入不支持此模型；已有直接摊牌跟注 EV 仍由原分析显示。支持的翻后有限树和河牌范围比较始终作为优先参考。此表提供可检查的模型对照，不能替代它们或完整求解器。

## 验证

单元测试检查净筹码会计、对手弃牌时未跟注筹码退回、再加注损失、有效全下上限、后续试探分支、加注合法性、失配记录和缺失结果。浏览器测试覆盖自动更新、假设调整以及新状态不复用旧 EV。
