# 第二期：翻前规则与自动行动范围

本期不增加必填项。继续逐步记录，快速分析自动选择适用能力；基础权益先出，范围修正随后显示。

## 翻前建议

`frontend/src/preflopAdvice.ts` 保存项目自定、版本为 v1 的保守教学规则。这些规则没有外部策略表来源，未经求解器或实战回测验证，不是 GTO、推弃表或盈利保证。UI 会直接标明规则性质，不将模拟权益当成开池依据。

识别开局参与座位中的 BTN、SB、BB、CO 和前中位；空座不占位置。按两张底牌所属牌型、位置、有效剩余筹码、跛入人数和单次加注生成倾向。有效筹码取自己剩余筹码与最大在局对手剩余筹码的较小值；同时存在更短对手时，该值不代表每个边池的深度。

范围在 `preflopRules` 中可审阅：前位、中位、后位开池范围，面对单次小额加注的防守范围和优质牌范围。无人加注时，40 BB 以上参考 2.5 BB，否则参考 2.2 BB，每个跛入增加 1 BB；优质牌面对单次加注参考原总额的三倍。最终总额向上取整并满足最小加注。明确显示“本街加注至”与“本次追加”，不混淆两个金额。

只在完整记录、自己行动、牌面与底池/跟注额一致时显示。20 BB 以下、有人全下、自己已经行动或已有多次加注时不自动推荐动作。建议加注若超过有效筹码的 30%，或非优质防守牌面对超过 4 BB 的总额/超过有效筹码 10% 的跟注额，提示复核。未开放加注权时不推荐再加注；免费决策不建议弃牌。没有计算加注 EV，短筹码和复杂行动树留待专门模型。

## 自动行动范围

新增 `history-ranges` 后端策略。前端仅在完整逐步记录、轮到自己、至少一名仍设为随机手牌的在局对手已有非盲注行动时自动请求；先完成原有 10,000 次快速分析，再提交独立的 10,000 次行动范围分析。河牌下注模型已适用时直接沿用该模型，不再额外提交本策略。

服务端重放完整历史并校验公共牌、座位、投入、底池和跟注额。对每名随机对手，复用 `history-rules-v1` 行动/尺度似然模型，从均匀翻前先验重算其后验。手动当前范围和明牌不变，不能把它们误作翻前先验后再次应用历史。每次计算独立重建，撤销、刷新或重新分析不会累乘旧后验。已知明牌和公共牌参与阻断；各对手独立推断，再由既有权益引擎处理无牌冲突的联合抽样及主池/边池资格。

修正完成后，权益标签改为“行动修正权益”，跟注参考 EV 和建议同步使用相同结果。可展开每名随机对手的证据数、合法组合数、有效组合数及粗略价值牌占比。有效组合数为权重归一化后概率平方和的倒数；价值类是当前粗粒度特征分类，不是获胜概率。

行为模型未校准，本策略仅计算基准假设，不宣称偏紧/偏松稳定性。模型失败可独立重试，原基础权益保留；输入变化会取消旧请求并立即隐藏其结果，包括尚未返回任务编号的提交。手工局面不伪造位置、筹码或历史。

## 验证

- 后端：历史校验、均匀先验重建、可重复性、取消、多人座位与手动范围混合。
- 前端：翻前位置、合法金额及增量、免费过牌、短筹码/再加注边界、输入一致性。
- 浏览器：真实 API 行动范围分析、基础结果先出、撤销恢复、手机布局，以及一期河牌自动分析回归。
