# 第三期：翻牌/转牌有限行动树 v1

## 使用

继续逐步记录，无新增必填项。在开局即单挑、自己为庄位（翻后后位）、完整筹码与历史齐全，且轮到自己最后行动的翻牌/转牌局面，快速分析会在基础权益及适用的行动范围分析完成后自动运行 `postflop-tree`。不适用的局面继续显示原有权益与范围分析，并在适用条件中说明边界。

面对下注时比较弃牌/跟注；无需跟注时比较过牌与约 1/3、2/3、1 倍底池的下注。金额按最小下注及双方有效剩余筹码裁剪、去重；只有自己全下才允许低于最小下注。若对手短筹码使所有候选下注不合法，则只展示过牌、明确说明未比较下注。

精细分析也可选择“翻牌/转牌有限行动树”。每情景最多 10,000 个样本，三个情景共最多 30,000 个样本；提高精细分析精度不会突破此初版计算上限。修改牌局会取消旧任务并立即隐藏其结论，失败可独立重试，基础/范围结果保持可用。

## 有限树的精确定义

1. 当前选择过牌、下注，或面对下注选择弃牌/跟注。当前下注后，对手仅弃牌或跟注，不再加注；当前面对下注不比较加注。
2. 未结束时，从合法剩余牌堆发下一张公共牌。到达下一街后，对手按其私牌及当时公共牌的粗粒度特征，以规则概率过牌或下注约半池。净匹配投入不超过双方剩余筹码。
3. 我方按自己的私牌、当时公共牌特征与赔率，执行固定跟注/弃牌策略；该策略不能读取对手私牌、尚未发出的公共牌或模拟的最终胜负。
4. 余牌发完且不再下注，按最终实际牌力分配底池。若已全下，直接发完余牌。

这是对明确固定策略的有限展开，不是求解所有节点的最优策略。未覆盖多人、边池、起初多人后转单挑、翻后前位、当前再加注或下一街其他尺度，也没有完整多街行动树。

## 范围、收益和误差

随机对手分别从均匀翻前先验按本手行动重建偏紧/基准/偏松后验，复用 `history-rules-v1`。明牌及手动当前范围保持不变；手动范围不再次应用行动证据，三情景仍改变后续响应假设。响应特征仅取对手自己的牌和当时公共牌，不泄漏用户底牌或私有死牌知识。

行为概率和牌力特征是项目内未校准启发式，不是 GTO 或实测对手反应。下一街“半池下注”概率及我方应对规则详见 `postflop_tree.py` 的 `continuation`；我方以粗粒度牌力特征是否达到赔率门槛加 0.1 决定跟注。这一特征并非精确权益，不应解释为最优跟注阈值。

模型 EV 以当前决策起的净筹码收益计，之前投入为沉没成本。当前对手弃牌收益为现有底池；当前自己弃牌收益为零；其他路径扣除自己此刻以后的投入。每个候选在同一情景共用同一批对手牌和发牌序列；对手响应概率解析积分，不再额外掷骰。比较领先候选时使用配对收益差的标准误，接近 1.96 倍标准误则提示临界，不给确定倾向。

界面区分基础/行动修正权益、直接摊牌跟注参考 EV 和有限树模型 EV，禁止将三者混为同一口径。动作表显示模型 EV、约 95% 抽样误差幅度、相对过牌/弃牌的差值及三情景结果包络；包络不是置信区间。三情景一致仅指所列候选的点估计最高动作一致，不是盈利保证。

## 验收与性能

测试覆盖翻牌/转牌动作集、确定性收益记账、相同种子可重复、共享样本、误差及筹码边界、手动范围/明牌、无效历史、座位与行动时机、取消、后台结果先后顺序、独立重试、延迟任务编号取消、精细分析入口和手机布局。

2026-11-01 本机单次直接引擎测量：每情景 10,000 次，共 30,000 次，转牌面对下注两动作约 1,032 ms；翻牌无需跟注四动作约 2,781 ms。使用测试中的完整历史及随机对手，时间不含基础权益、单独行动范围分析、任务排队、HTTP 和界面轮询。不是跨机器性能承诺；总任务继续受既有时间预算限制。
