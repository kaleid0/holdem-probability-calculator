# 边池感知权益分析

2026-11-01。适用于逐步记录中的快速分析和精细分析；手动局面仍兼容原单底池接口。

## 使用

记录不同筹码玩家的跟注/全下，补齐当前阶段的公共牌后，快速分析自动使用累计投入和弃牌状态。进入“精细分析”并执行，可查看各池金额、参赛资格、自己的权益及预期所得；未跟注退回单独列出。撤销、刷新恢复及对手范围编辑会更新分析输入，旧精细结果会标记过期。

按当前累计投入加上自己的本次跟注拆池，不预测其他玩家今后的跟注、加注或弃牌。弃牌筹码计入池金额，弃牌者不参加比牌；已知弃牌底牌仍作为死牌。

## 计算口径

每个精确状态或模拟样本只发一次公共牌及对手牌，同一副牌用于全部池。每池只比较有资格的玩家，平局按赢家人数等份分摊；不同池的收益相关性因此保留在总权益抽样误差内。范围权重、随机对手和指定牌使用同一拆池规则。

- 各池预期所得 = 池金额 × 自己在该池的权益。
- 总权益 = 全部争夺池中的预期所得之和 ÷ 全部争夺池金额。包含自己无资格参加的边池作为分母，不包含未跟注退回。
- 预期可得筹码 = 全部池预期所得 + 退回给自己的未跟注金额，尚未扣除本次跟注。
- 独赢/平局/输牌概率仍与全部在局对手比较牌力。可能整体输牌，但赢得某个边池。
- 平局不模拟整数余筹的庄位分配，预期所得可为小数；实际筹码结算仍使用现有整数分配规则。

例如自己持 KK，短码 AA 投入 100，深码 QQ 投入 200，自己已投入 100 并追加跟注 100，最终牌面均未改善：主池 300 由 AA 赢得，边池 200 由自己赢得。自己的总权益为 200/500 = 40%，预期可得 200，跟注 EV 为 200−100 = +100，整体输牌概率为 100%。

## 跟注 EV 边界

记录局面同时满足以下条件才输出跟注 EV、盈亏平衡权益与候选动作：

1. 正在由自己行动，本次跟注可闭合行动，其他待行动玩家均已全下或弃牌。
2. 明确选择跟注后无后续投入、发完公共牌直接摊牌。
3. 有正跟注额和争夺池，并且没有自己的未跟注退回。

EV = 预期可得筹码 − 本次跟注额，基准为此刻弃牌。盈亏平衡权益使用跟注额/全部争夺池金额，与总加权权益比较。展示的赔率使用自己可争夺的池金额扣本次跟注后与跟注额的比，不把无资格参加的池当作可赢筹码。

其他情况保留分池权益及预期所得，EV 留空并解释条件。权益余量规则仍只支持单池；多池比较会明确返回不支持，不套用单底池启发式。

## 接口

`AnalysisRequest.pot_context` 可选：`contributions` 按自己、在局对手的顺序记录跟注前累计投入；`folded_contributions` 保存弃牌者投入；两者之和必须等于 `pot_before_call`。`betting_closed_after_call` 默认 false，调用者需根据真实行动状态明确提供。

结果新增 `pots`（金额、参赛者索引、是否退回、自己权益、预期所得）与 `expected_return`。参赛者索引 0 为自己，1 起对应本次请求过滤弃牌者后的对手顺序。未提供 pot_context 的旧请求保持原有单底池口径；场景保存格式不变，逐步记录投入由已有会话恢复。
