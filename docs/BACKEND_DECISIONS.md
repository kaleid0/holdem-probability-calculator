# 行动建议职责边界

2026-11-02：将原前端的翻前规则、后续行动启发式、当前候选 EV、抽样临界判断和建议优先级迁至后端。模型假设保持原义，本次迁移不把启发式升级成求解器。

## 分层

| 模块 | 职责 |
| --- | --- |
| `domain/advice.py` | 严格请求、结构化建议、响应模型与候选 EV 合约 |
| `domain/decision.py`、`domain/history.py` | 重放事件，恢复行动者、投入、最小加注与加注权 |
| `engines/action_ev.py` | 基于既有权益计算有限响应模型的候选 EV、误差与情景比较 |
| `strategies/preflop_advice.py` | 项目自定翻前范围与金额规则 |
| `strategies/continuation_advice.py` | 明确标识的保守跟注／过牌参考 |
| `strategies/decision_advice.py` | 基线、河牌与有限树结果的决策解释 |
| `application/advice.py` | 通过可注入的结果来源读取任务，核对局面与历史，统一选择建议 |
| `api/main.py` | HTTP 输入输出与错误映射 |

领域、引擎和策略不依赖 FastAPI。新模块执行 Ruff（E/F/I/UP/B、100 字符行宽）、严格 mypy 和后端回归测试。

## 接口

`POST /api/v1/decision-advice` 接收：

- `base_analysis`：当前分析输入；不接受浏览器提供权益或分析结果。
- `recorded`、`history_context`、`opponent_seats`：录入模式、完整有序历史和座位映射。
- `sources`：可选的 `baseline`、`history`、`river`、`tree` 已完成分析任务 ID。
- `response_model`：可选的弃牌、再加注、试探概率；默认 25%、8%、35%，非有限值和概率和大于 1 时拒绝。

服务直接读取任务保存的原始输入与结果，核对策略及局面。高级结果还必须匹配本手历史和截止序号。翻前规则不依赖模拟完成，基础结果和高级结果到达时可分别请求建议，不增加概率计算任务。

返回 `advice`、`opening_advice`、`fallback`、`fallback_reasons`、`comparison`、`response_model` 和模型版本。建议包含来源、模型版本、状态码、动作、金额口径、解释、稳定性，以及适用时的门槛和余量。状态码参与决策，中文标题仅用于展示。

选用顺序：有限树、河牌比较、覆盖内翻前建议、可用基线建议、后续行动参考、翻前复核、基线说明。非本人行动时不提供动作建议。

错误：不存在的任务返回 404；尚无可用结果返回 409；过期返回 410；局面、策略、历史或配置不一致返回 422。任务仍遵守当前单实例、内存保存及 TTL 约定。

## 前端边界

`useDecisionAdvice` 只提交输入与任务 ID，处理请求、重试、取消及响应身份检查。输入、行动、撤销或响应假设变化后立即隐藏旧建议和 EV；迟到响应不能覆盖当前状态。服务失败时展示错误及重试入口。

前端保留选牌、表单校验、范围编辑预览、策略可用条件预览、任务轮询、录入状态、撤销和本地保存。`liveGame.ts` 的本地记录与手工确认结算规则仍保留；涉及后端建议时，以后端历史重放为准。本次未引入服务端牌局会话或在线对战结算。

候选 EV 仍是与手牌独立的有限响应情景模型；保守余量仍是项目规则，均不代表完整行动 EV、GTO 或已校准概率。
