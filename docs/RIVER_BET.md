# 河牌下注 EV

在「精细分析 → 分析设置」勾选「河牌下注 EV」，默认使用自动模式。使用逐步记录保存本手行动，到河牌由自己最后行动时点击「执行精细分析」，无需填写筹码、弃牌率和跟注范围。手动模式可覆盖响应假设。快速分析仍只计算权益；设置随牌局保存、导出和恢复。缺少模式字段的旧页面存档默认使用自动模式，原手动字段仍保留，切换后可继续使用。

支持河牌、单挑、正底池、无需跟注且没有边池的局面，适合对手已过牌、自己最后行动的决策。下注后对手只会弃牌或跟注，不加注，不计抽水与 ICM。

## 自动推断

系统将完整本手历史、座位映射和开局筹码提交后端，逐事件重放验证：

- 根据实际投入扣减双方开局筹码，取剩余筹码较小值作为有效筹码。
- 根据合法行动顺序恢复当前行动者和待行动玩家，要求当前只有自己待行动；不信任客户端的过牌闭合声明。
- 自动生成 1/3、1/2、3/4、1、1.5 倍底池及全下候选，按有效筹码、最小下注、整数约束去重，最多 6 个金额。
- 复用 `history-rules-v1`，从全组合等权翻前先验开始，按对手实际行动及尺度逐街更新组合权重。可选提供翻前先验；不把当前范围编辑器结果再次应用历史，避免重复计数。指定对手明牌时保持该手牌固定。
- 对每个后验组合，用完整河牌牌力计算其对均匀未知手牌的权益参照，严格剔除该组合自身的两张牌阻断。只输入公共牌及对手自己的手牌，不把自己的隐藏手牌或私有死牌信息传给对手响应模型。使用权益参照与跟注赔率的差值估计响应，再汇总弃牌率和条件跟注权益，两者来自同一组组合概率。
- 对手参照权益为 E，所需跟注权益为 `B/(P+2B)`，基准跟注概率为 `sigmoid(10×(E−B/(P+2B)))`。这是显式启发式而非已拟合概率；确定跟注不会输时跟注概率固定为 1，确定无任何获胜或平局可能时为 0。公共牌皇家同花顺等必平局面不会凭空产生弃牌收益。
- 自动执行基准、偏紧、偏松三种情景：历史诈唬权重分别为 0、−1.2、+1.2，响应 logit 平移分别为 0、−0.8、+0.8。每种情景独立从同一翻前先验推断，不把某个情景的后验当成另一个情景的先验。

结果列出模型版本、历史截止序号、来源、有效筹码、有效组合数、对手行动数及逐街依据。另提供按概率排序的后验手牌类别、组合数与权重集中度（等权组合折算 `1/Σp²`）。这表示范围集中程度，不是统计样本量或置信度。

每个候选动作提供基准 EV、相对过牌的差值、三情景 EV 最小/最大值，下注收益拆为弃牌分支与跟注分支。三情景对照分别展示权益、过牌 EV、最高候选 EV 和全部并列动作；只有三个情景的最高动作集合存在交集时标记「三情景一致」，否则提示建议依赖假设。情景范围是指定假设的结果包络，不是统计置信区间。

如果非基准情景因后验精度不足等输入问题无法完成，保留基准与其他已完成结果，标注失败原因，不声称三情景一致；EV 范围仅覆盖已完成情景。取消和超时仍遵循整个任务的预算，不静默跳过。

仅使用截止当前的本手行动，不建立跨手对手身份画像。模型未用真实对局校准，预测比例不是测量值；对推断后验精确枚举也不代表行为预测无误差。快速分析仍使用当前范围编辑器，与本策略历史后验的权益可能不同。

页面在运行前显示缺少公共牌、非单挑、需要跟注、行动顺序、筹码或记录不一致等原因；后端独立重放历史复核。无效历史返回信息不足，不猜测事实，也不静默退回随机范围。切换手动模式时可自动补入已知有效筹码和可验证的过牌闭合状态，保留已有手动字段。

API 自动请求示例见 [river-auto-analysis.json](../examples/river-auto-analysis.json)：`river-bet` 的配置只需要 `mode: "auto"`、`opponent_seats` 和 `history_context`，不传手动下注参数。原有缺少 `mode` 的 API 请求继续按手动方式解释以保持兼容。自动模型版本为 `history-river-response-v2`，策略版本为 `0.3.0`。

## 数学口径

P 是决策前底池，B 是下注，F 是对手弃牌率，E0 是面对当前范围的权益，Ec 是被跟注后的条件权益。权益包含平局平分。

```text
EV(check) = E0 × P
EV(bet) = F × P + (1 − F) × [Ec × (P + 2B) − B]
```

基准是从当前决策起的净筹码收益，之前投入作为沉没成本。对手弃牌时，未被跟注的下注退回，因此净收益是 P。它不同于底池赔率策略以现在弃牌为零点的跟注参考 EV，不能跨策略直接排名。

上方权益是 E0。候选表过牌行显示 E0，下注行显示 Ec；F=100% 时不计算 Ec。河牌权益使用精确枚举，不受模拟精度选项影响。最高 EV 仅表示已配置方案在当前响应假设下的最高值，并列时列出全部并列动作，不代表 GTO 或全部下注金额的全局最优。

## 手动响应配置

每个方案独立指定弃牌率（默认 0%，不假定对手会弃牌）和可选的条件跟注范围。

- 留空范围：Ec 沿用当前范围，假设弃牌与手牌无关。
- 指定范围：沿用现有范围文本语法、权重和已知牌阻断。它表示已经跟注时的条件分布，不是每个组合的跟注频率。
- 剔除已知牌后，跟注范围必须来自当前范围。每个组合 i 必须满足 `(1−F) × q(i) ≤ p(i)`，p 是当前范围归一化概率，q 是条件跟注范围归一化概率。这保证剩余概率可以构成合法弃牌分布。否则提示提高弃牌率或扩大跟注范围。
- F=100% 时，条件范围不参与收益和一致性计算；如填写文本，仍需符合语法。

例如当前范围 `AsAh, QsQh` 两者等权，仅 `AsAh` 跟注时，对手至少须弃牌 50%。只弃牌 10% 会凭空增加 AA 的出现概率，策略将报告信息不足。

导入 [示例牌局](../examples/river-bet.json)：自己 KK、对手 AA/QQ 各半、底池 100；过牌 EV 为 50，下注 50、对手弃牌 50% 且仅 AA 跟注时 EV 为 25，因此推荐过牌。

## 接口

沿用 `/api/v1/analyses`，策略 ID 为 `river-bet`，配置示例：

```json
{
  "id": "river-bet",
  "config": {
    "mode": "manual",
    "effective_stack": 200,
    "check_closes_action": true,
    "bets": [
      {"amount": 50, "fold_probability": 0.5, "calling_range": "AsAh"},
      {"amount": 100, "fold_probability": 0, "calling_range": ""}
    ]
  }
}
```

缺失筹码或过牌闭合确认、跟注范围不一致时返回策略级 `insufficient-data`；街道、人数、跟注额、边池不支持时返回 `unsupported`；配置语法错误返回策略级 `error`。多策略任务保留其他完成结果。旧的单策略提交方式沿用原有 422 校验。

候选动作扩展 `check`、`bet`，提供可空的 `fold_probability`、`showdown_equity`。自动结果额外提供 `inference` 元数据。`call_ev` 保持空值，避免把下注收益误标为跟注收益。手动模式的弃牌率由用户设定，自动模式由历史后验和响应规则估计。
